# Editable draw.io figures

One `.drawio` file per process figure in the report. Figure numbers match the Word report.

| File | Report figure |
|---|---|
| Figure1_AML_operations_transformation_model.drawio | Figure 1: input–transformation–output model |
| Figure3_order_to_delivery_swimlane.drawio | Figure 3: order-to-delivery swimlane map |
| Figure4_Gaydon_build_flowchart.drawio | Figure 4: Gaydon build flowchart |
| Figure6_supply_chain_map_CODP.drawio | Figure 6: supply chain map with decoupling point |
| Figure8_Fisher_product_supply_chain_matrix.drawio | Figure 8: Fisher product–supply chain matrix |
| Figure9_inventory_flow_control_points.drawio | Figure 9: inventory flow and control points |
| Figure12_sustainability_initiatives_outcomes.drawio | Figure 12: sustainability initiatives, outcomes and stakeholder effects |

Open at app.diagrams.net (File → Open from device) or in the draw.io desktop app. Text is editable by double-clicking a box; dashed boxes are inferred steps, red boxes are bottlenecks.

The charts (Figures 2, 5, 7, 10 and 11) are data charts rather than diagrams, so they are not in draw.io format. Their editable vector versions are the `.svg` files in `figures/`.
