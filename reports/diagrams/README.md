# Editable diagrams

Each `.mmd` file is one figure from the report, as Mermaid source. They are identical to the code blocks in `../Aston Martin operations management.md`.

How to edit:
- **mermaid.live** — paste a file in, edit, then export PNG/SVG for your Word document.
- **draw.io / diagrams.net** — Arrange → Insert → Advanced → Mermaid, paste the code. You can then move boxes and restyle freely.
- **VS Code / GitHub / Obsidian** — the code blocks render directly in Markdown.

If you change a diagram here, copy the change into the report too (or vice versa).
